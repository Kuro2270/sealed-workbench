# GitHub Actions 早見表

Actions の一覧は名前順に並ぶので、頭の「データ｜」「ショート｜」「長尺｜」などで組ごとにまとまる。
名前の末尾に「（自動・…）」が付いているものは、**押さなくても動く**。「（手動）」は押したときだけ動く。「（push時）」は、対象のファイルを GitHub に上げたときだけ動く。

時刻はすべて日本時間。

## 全体の流れ（新セットが出てから）

```
データ｜1 新データの点検 ──(発売2〜3日目・試合数が揃った)──▶ ショート｜1 環境まとめ動画を作る（mode=early）
          │                                                      先行版のショート（日英2本・非公開で上がる）
          │                                                        ★ 公開にする → ショート｜2 動画を配信
          │
          └──(発売12日目・公開データあり)──▶ データ｜2 勝率データ集計
                                                   │
                                                   ▼
                                   ショート｜1 環境まとめ動画を作る（4本・非公開で上がる）
                                                   │
                                     ★ YouTube Studio で内容を見て「公開」にする（手作業）
                                                   │
                                                   ▼
                                   ショート｜2 動画を配信（手で押す。サイトに載せ、SNS に案内）
                                                   │
                                        （ショート公開の14日後）
                                                   ▼
                        長尺｜1b 自動作成の起動 ──▶ 長尺｜1 長尺動画を作る（日英・非公開で上がる）
                                                   │
                                     ★ YouTube Studio で内容を見て「公開」にする（手作業）
                                                   │
                                                   ▼
                                   長尺｜2 長尺動画をサイトに載せる（毎日 自動。すぐ載せたいときは押す）
```

手作業は「公開にする」の3か所と、「ショート｜2 動画を配信」を押すことだけ。

### 先行版と本編の2段構え

| | 先行版 | 本編 |
|---|---|---|
| いつ | 発売2〜3日目（17Lands の PremierDraft が 25,000 試合を超えたら） | 発売12日目以降（17Lands の公開データが出たら） |
| 何を | ショート（日英）だけ。ドラフト＋シールドを合算した「リミテッド速報」 | ショート4本（日英 × ドラフト/シールド）→ 2週間後に長尺 |
| データ | 17Lands のカード勝率・色別勝率（形式ごとに2回、計4回の取得） | 17Lands の公開データ（CSV） |
| サイト | 数字の表は**載せない**（17Lands の決まりで、サイト掲載は12日目から）。速報の動画だけ、「動画を配信」のあとに下見ページ・環境レポート（下見表示）・トップの「最新のセット」に出る | セット別ページ・環境レポートに載せる |
| 手で作るとき | 「ショート｜1」で `mode=early`、`lang=both` | いつもどおり |

先行版の動画は、本編のセット別ページができたあと、ドラフトの欄に「発売直後の速報（動画）」として並ぶ。

## 自動で動くもの

| 名前 | いつ | 何をするか | 外に出るもの |
|---|---|---|---|
| データ｜1 新データの点検 | 毎日 3:30 | 17Lands に新セットの公開データが出たか見る。出ていれば「データ｜2」を起こす。発売直後のセットは試合数を見て、揃っていれば先行版のショート（「ショート｜1」の mode=early）を起こす。発売前後のセットの「下見」ページも作る | 先行版の起動のみ |
| データ｜2 勝率データ集計 | 毎週月曜 3:00 と、データ｜1 が起こしたとき | 記事データ・環境レポート・r/lrcast 下書きを作る。新セットなら「ショート｜1」を4本（日英 × ドラフト/シールド）起こす | サイト更新 |
| ショート｜1 環境まとめ動画を作る | データ｜2 が起こしたとき（本編）／データ｜1 が起こしたとき（先行版）。手でも押せる | ショート動画を作り、YouTube に**非公開**で上げる。`mode=early` のときは 17Lands から直接データを取って先行版を作る | YouTube（非公開） |
| 長尺｜1b 自動作成の起動 | 毎日 9:10 | ショート（日本語・ドラフト）の公開から14〜28日のセットで、長尺がまだ無ければ「長尺｜1」を**日英・アップロードあり**で起こし、確認の Issue を立てる | Issue |
| 長尺｜1 長尺動画を作る | 長尺｜1b が起こしたとき（手でも押せる） | 長尺動画を作り、YouTube に**非公開**で上げる。日英は別ジョブで並行。1〜2時間かかる | YouTube（非公開） |
| 長尺｜2 長尺動画をサイトに載せる | 毎日 12:17 | 公開になった長尺を `data/long.json` に登録し、動画に呼びかけのコメントを付け、セット別ページを作り直す | **YouTube にコメント**、サイト更新 |
| SNS｜SNS 定期投稿 | 毎週金曜 12:00 | X・Bluesky に週次の投稿 | **SNS に投稿** |
| サイト｜商品ページを更新する | 毎週月曜 6:17 | 楽天の商品情報を取り直してページを作る | サイト更新 |
| 点検｜メンテナンス点検 | 毎週月曜 9:00 | 未登録のセット名などを点検して Issue で知らせる | Issue |

## push したときに動くもの

| 名前 | 動く条件 |
|---|---|
| サイト｜セット別ページを作り直す | `data/long.json`・`data/videos.json`・`maintenance/build-set-pages.mjs` を上げたとき |
| サイト｜ロゴを軽くする | `short/logo/` の画像か `maintenance/build-logos.mjs` を上げたとき |
| サイト｜対戦卓サーバーを配置 | `worker/` を上げたとき |

いずれも手で押すこともできる（入力なし）。

## 手で押すもの

| 名前 | いつ押すか | 入力 |
|---|---|---|
| ショート｜2 動画を配信 | ショートを YouTube Studio で公開にしたあと | ふつうは空欄。`set` で絞る／`post` で SNS 投稿の有無／`comments` に SOS や ALL で、コメントだけ付け直す |
| 設定｜YouTube 投稿許可 | 投稿やコメントが 401/403 で続けて落ちるとき | 1回目は空欄で実行 → ログの URL を**そのチャンネル**で開いて許可 → 出てきた localhost の URL を `device_code` に貼って2回目 → ログの `1//…` を `YT_REFRESH_TOKEN_JA`（英語なら `_EN`）に保存 → ログを削除 |
| 設定｜X 投稿許可 | X の投稿が落ちるとき | 1回目は空欄 → PIN を取って2回目 |
| 設定｜セット名を登録 | 点検の Issue で未登録を知らされたとき | `code`（例: fra）と `name`（日本語の正式名称） |
| 補助｜セットの下見を作る | 下見ページを作り直したいとき | `set` |
| 補助｜動画のサムネイルだけ作る | 昔の動画のサムネイルを揃えたいとき | `set` |
| 補助｜r/lrcast 下書き | 文面を直して作り直したいとき | `set` |

## 言語の指定（共通）

動画・投稿にかかわるワークフローの `lang` は、すべて同じ選び方。

| 値 | 意味 |
|---|---|
| `both`（既定） | 日本語と英語の両方 |
| `ja` | 日本語だけ |
| `en` | 英語だけ |

- ショート｜1、長尺｜1：その言語の動画を作る（ショート｜1 の `mode` は `both / draft / sealed / early`）
- 長尺｜2：その言語のチャンネルを調べる。ふだんは `both` のまま。`video_id` で動画を指定するときだけ、その動画の言語を `ja` か `en` にする（`both` だと止まる）
- SNS｜SNS 定期投稿：その言語で投稿する（Bluesky は `bsky_langs` で別に決める。既定は英語だけ）

## 日本語と英語のチャンネル

| | 日本語 | 英語 |
|---|---|---|
| チャンネル | @sealedworkbench_jp | @sealedworkbench |
| 許可（Secrets） | `YT_REFRESH_TOKEN_JA` | `YT_REFRESH_TOKEN_EN` |
| 長尺の題 | 「【セット名】…環境まとめ」 | 「[MTG Arena] <Set> Limited Review \| …」 |

クライアント ID（`YT_CLIENT_ID` / `YT_CLIENT_SECRET`）は日英で共通。

英語チャンネルは、YouTube が有効なトークンをときどき「無効」と返すことがある（2026年10月時点）。投稿も掲載も、落ちたら待って取り直すようにしてあるので、ログに `401 なので、待ってトークンを取り直します` と出ていても、そのあとに `登録しました` や `付けました` が続いていれば正常。

## 困ったとき

| 症状 | 見るところ |
|---|---|
| 動画が上がらない | 「ショート｜1」「長尺｜1」の「YouTube に上げる」の手順。401/403 が3回続くなら「設定｜YouTube 投稿許可」 |
| 公開したのにサイトに載らない | ショートは「ショート｜2」を押す。長尺は「長尺｜2」を押して、ログの `登録しました` を見る |
| セット別ページが古い | 「サイト｜セット別ページを作り直す」を押す。ログの末尾に push の結果が出る（失敗なら赤くなる） |
| コメントが付かない | 「長尺｜2」のログの `コメントを付けられませんでした（…HTTP …）` の行に、YouTube の理由が出る |

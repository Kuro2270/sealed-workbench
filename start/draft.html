ドラフトの基本

パックを回しながら1枚ずつカードを取り、40枚のデッキを作るのがドラフトです。何を取るか・いつ色を決めるかの基本をまとめました。

3行まとめ

  1. 最初の数手は、色にこだわらずいちばん強いカード
  2. 2パック目の前半までに2色にしぼる
  3. 遅い手番で強いカードが流れてくる色は空いている

ピックの流れ

  1. 1パック目14枚から1枚取り、残りを左へ回す
  2. 2パック目今度は右へ回す
  3. 3パック目また左へ回す
  4. デッキを組む取った42枚から23枚＋土地17枚

デッキの組み方は、シールドと同じです。シールドの組み方の手順で進めてください。

時期ごとの取り方

時期取るもの

1〜5手目		色にこだわらず、いちばん強いカード。ボム ＞ 除去 ＞ 強いクリーチャーの順

空いている色の見つけ方

🔍遅い手番を見る

6手目以降に、その色の強いカードがまだ残っていれば、上流（渡してくる人）はその色を取っていません。

🔁向きを覚える

1パック目と3パック目は同じ向き。1パック目で空いていた色は、3パック目でも流れてきやすいです。

⚖️こだわりすぎない

1枚の強いカードのために、流れてこない色を続けるより、空いている色に移るほうが結果は良くなりがちです。

クイックドラフトは、ほかの7人がコンピューターです。流れの読み方は目安くらいに考えてください。

データで見るドラフト

このサイトの環境レポートを、セットをまたいで集計しました。

13/15セット
ドラフトは、軽いデッキが有利

軽いデッキ（平均マナ総量2.9未満）が、重いデッキ（3.5以上）より勝っています。差は平均1.5ポイント。重いカードの取りすぎに注意。

1.3ポイント
3色デッキは2色より勝率が低い

2色56.1%・3色54.8%。3色デッキは全体の約8%です。ドラフトでは2色にまとめるのが基本です。

集計：15セット・2026-10-21時点のデータ。数字はデータの更新で変わります。

よくある失敗

  • 1手目の色に最後までこだわる→流れを見て、2パック目の前半までに乗り換える
  • レアや重いカードばかり取る→2マナのクリーチャーと除去を、中盤から意識して取る
  • 3パック目でも強いカードを取り続ける→自分の2色で使えるカードを優先する。使えないカードは0点

次の一歩
